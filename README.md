## 🚀 Projects

**[Home-Lab](https://github.com/duckdarsh-04/Home-Lab)**: My self-hosted infrastructure: NixOS servers running 20+ Docker services, with monitoring and encrypted secrets via sops-nix. Everything is declared in code and deployed with Colmena, so the whole setup can be rebuilt from scratch.

**[DuckOS](https://github.com/duckdarsh-04/DuckOS)**: My custom NixOS distro, built as a single flake with desktop and server profiles. It ships a Hyprland desktop, Neovim configured through nvf, and Home Manager, and it is themed with Stylix. Machine-specific settings live in a gitignored `personal.nix`, so anyone can clone it, fill in their own details and get the same system.
